# ld2-editor

Редактор контента ld2: карта мира, локации и выходы, мобы/НПС/объекты,
предметы, диалоги, магазины, квесты, рецепты, навыки и профессии.
Стек — **gpui + Ely** (как игровой клиент), тёмная палитра, русский UI.

Источник правды — файлы `content/*.json` в git (не БД): редактор пишет их
атомарно (временный файл + `rename`), с валидацией и картой мира. Скрытого
состояния нет: всё, что видно в редакторе, лежит в файлах и уходит в git.
Сервер применяет изменения через `ld2-server seed` или hot reload
(`[world] content_poll_s`, SIGHUP, `cmd/admin.content.reload`).

План итераций: `plans/PLAN-M27-EDITOR.md` (E0–E6).

## Статус

- **E0** — каркас крейта и окна.
- **E1** — общий крейт `ld2-content`: схема, load, сохранение без потерь,
  каноническая версия контента.
- **E2** — ядро редактора: проект, индекс, atomic save, undo/redo,
  формы предметов; CLI `--check` / `--normalize-content`.
- **E3** — локации: выходы и сущности, добавление/удаление/правка.
- **E4, E4.2** — карта-полотно: раскладка, зум/панорама, перетаскивание
  узлов, создание и удаление связей drag'ом узла на узел.
- **E5.1** — квесты, рецепты, навыки, профессии: формы, подсписки, пикеры
  ссылок.
- **E5.2** — диалоги (строки, реплики, обучение, условия) и магазины
  (валюты, ставки, товары).
- **E6** — полировка: `Ctrl+P` быстрый переход, раздел «Помощь», кнопка
  «Seed» (применить контент на сервере), версия контента включает все
  8 файлов, CI-артефакты.

## Запуск

```bash
cargo run -p ld2-editor                    # окно редактора (ищет content/ вверх от CWD)
cargo run -p ld2-editor -- --version
cargo run -p ld2-editor -- --check content          # валидация и версия без GUI
cargo run -p ld2-editor -- --normalize-content      # канонический pretty-формат всех 8 файлов
```

## Инструкция контент-мейкера

1. **Получить свежий контент.** `git pull` в своей ветке `develop`.
2. **Править.** Раздел слева (или `Ctrl+P` — быстрый переход по любому
   id/имени), средний столбец — список и поиск, справа — форма.
   Подсписки (выходы, сущности, реплики, цели, ингредиенты, товары)
   выбираются кликом по строке.
3. **Ссылки.** Кнопки «… предмет / навык / НПС / локация» открывают пикер:
   начните вводить id или имя, выберите — id подставится в поле.
4. **Сохранить.** `Ctrl+S` (или «Сохранить»). Красные ошибки блокируют
   запись; жёлтые предупреждения — висячие ссылки, их можно оставить,
   но лучше починить. Undo/Redo — `Ctrl+Z` / `Ctrl+Shift+Z`.
5. **Проверить диф.** `git diff content/` — редактор сохраняет порядок
   ключей; незнакомые ему поля не теряются.
6. **Закоммитить и запушить** изменения (Conventional Commits, русский).
7. **Применить на сервере.** Кнопка «Seed» в шапке (по умолчанию
   `cargo run -q -p ld2-server -- seed`; свой конфиг — переменная
   `LD2_EDITOR_SEED_CMD`). Версию контента на сервере смотрите в
   `curl -sI http://<server>/healthz | grep x-ld2-content-version`.
   В production допустим hot reload без перезапуска: положить файлы в
   `content/` рядом с сервером — watcher подхватит через `content_poll_s`
   секунд (или `docker compose kill -s HUP server`).

## Горячие клавиши

| Клавиши | Действие |
| --- | --- |
| `Ctrl/Cmd + P` | быстрый переход по разделам и записям |
| `F1` | справка (раздел «Помощь») |
| `Ctrl/Cmd + S` | сохранить изменённые файлы |
| `Ctrl/Cmd + Z` | отменить правку |
| `Ctrl/Cmd + Shift + Z` / `Y` | повторить правку |
| `Ctrl/Cmd + R` | перечитать файлы с диска |
| `Enter` в форме | применить форму |
| карта: `←↑→↓`, `+`/`-`, `L` | сдвинуть узел, зум, режим связей |

## Ограничения

- Редактор пишет все 8 файлов (`locations`, `skills`, `items`,
  `professions`, `recipes`, `quests`, `dialogs`, `shops`) в каноническом
  pretty-формате; `--check` и seed считают версию по всем файлам.
- Правки карты (раскладка) хранятся отдельно в `content/editor/layout.json`
  и не влияют на серверный контент.
- Кнопка Seed запускает команду с конфигом по умолчанию; для production
  укажите `LD2_EDITOR_SEED_CMD` (например, `ld2-server --config
  /etc/ld2/server.toml seed`).
