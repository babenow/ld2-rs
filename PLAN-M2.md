| # | Содержание | Критерий |

| **M2.3** | **UI-экраны** (`ui/`): вход (форма+ошибка+статус), выбор персонажей (карточки, счётчик n/limit, бейджи статусов, удаление с подтверждением), мастер «имя+профиль» (Воин/Вор/Маг, D3), заглушка «Игра» со сменой персонажа (hot-switch), логаут; keyring-resume при старте (без логина) | ru/en-строки (D8, паритет ключей), все действия через transport-хендл |

Порядок: M2.1 → M2.2 → M2.3 → M2.4 → PR → CI → squash в `develop` → тег `m2-done`.

## Правила

Типы контракта — только `ld2-protocol`; лимиты — из `session.start`; коммиты RU + `Milestone: M2`; ветка `feature/M2-*`; PR только после зелёного CI.

## Риски

- egui 0.37 (новый API `App::ui`) — формы/модалки писать по фактическим сигнатурам;
- keyring на CI — smoke уже с покрытием окружения (пропуск при отсутствии хранилища);
- размер app.rs — выносить экраны в `ui/`, не раздувать.
