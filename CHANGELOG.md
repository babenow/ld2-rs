  инкрустации переехал из-под панели действий в левую колонку; фикс:
  прогресс заточки не отображался (длительность сравнивалась с
  epoch-мс как дедлайн → `upgrade.start` уходил мгновенно)
- переключение разделки на другой труп (M24): старт на другом трупе
  разрешён и прерывает текущее действие — шкура брошенного трупа
  портится (gut и skin: `skin_done`, повтор снятия невозможен, gut
  повторить можно); итог прерывания и обновление трупа — до ack,
  клиент гасит бар только по итогу своего трупа; повтор на том же
  трупе — `E_COOLDOWN`
- разделка (M24): пока идёт таймер, **действия персонажа
  блокируются** (`E_BUSY`); **урон прерывает** процесс — снятие
  шкуры → кожа испорчена (повтор невозможен, без шкуры и опыта),
  освежевание → отмена (повтор можно); механика M23 по предметам
  сохранена
- фикс заточки/улучшения **стака**: применяется к ОДНОЙ штуке —
  старый стак −1, улучшенный предмет добавляется отдельной строкой;
  разрушение (Break) гасит одну штуку, уровень стака не меняется
- выдача в сундук — **один стак с указанным количеством** (слияние
  с уже лежащим стаком того же предмета; взятие выдаёт ровно это
  количество), частичное удаление из стака; магазин — одна позиция
  на предмет
- лимит количества в админ-диалоге: 1..=999, **кроме валюты**
  (`type=money` — без потолка, до INTEGER-стака в БД)
- **закрыта дыра из бэклога**: `/scenario …` теперь только для
  админа либо при `server.allow_scenario` (dev/тесты; в прод-конфиге
  ключ отсутствует → запрещено)

  отмена (Esc/скрим) сбрасывает
- фикс `tf`: нормализация имени плейсхолдера — `{s}` больше не ломает
  таймеры/кулдауны/бейдж; описания всех **33 навыков** из GDD
  (docs/skills.md §3) в контенте/БД; тултип ⓘ у навыков
- журнал **персонален**: очистка при входе/выходе из мира; чат прижат
  к верху, колонки с `min_w_0` — резиновая вёрстка; фикс прокрутки
  вниз (`scroll_to_bottom` вместо `scroll_to_item(len-1)` — индекс
  был несуществующим)
- **роли аккаунтов** `player|admin|moderator` — миграция 0014,
  назначение SQL: бейдж роли в шапке, `E_PERMISSION` для system-чата
  и `cmd/chat.delete`, `ChatMessage.id` — удалённые сообщения
  переживают рестарт
- поле ввода чата больше не вылезает за рамку (пол истории `min_h_0`)
- экран входа: предупреждения при включённом **Caps Lock** и на
  **русской раскладке** (чтение `window.capslock()`/TIS-раскладки в
  рендере + подписки на смену модификаторов/раскладки)
- **реплей истории чата** помечен `extra.replay` — клиент не показывает
  прошлую сессию: журнал и чат входят в игру пустыми (кольцо
  `server_history` сохранено)
- Windows: окно снова перетаскивается за заголовок (hit-test
  `WindowControlArea::Drag` → `HTCAPTION`) и получает кнопки
  сворачивания/разворачивания/закрытия в стиле системы (ely
  `WindowControls`); на macOS — системные «светофоры» без изменений
- l10n ru/en: **29** новых ключей; тесты **209** (gated PostgreSQL)
