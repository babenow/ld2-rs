# ld2 — руководство пользователя

Настольный клиент текстовой онлайн-MMORPG **ld2** (eframe/egui, Rust).
Версия документа соответствует релизу **v0.9.0** (M9).

---

## 1. Установка и запуск

### Готовые сборки (релизы GitHub)

| ОС | Артефакт | Запуск |
|---|---|---|
| Windows 10+ | `ld2-<версия>-windows-x86_64.zip` | распаковать, запустить `ld2-client.exe` |
| macOS 12+ | `ld2-<версия>-macos.dmg` (universal) | перетащить `ld2.app` в Applications |
| Linux (glibc 2.31+) | `ld2-<версия>-linux-x86_64.tar.gz` или `.deb` | распаковать / `dpkg -i`, запустить `ld2-client` |

В артефакт входит и `ld2-mock-server` — локальный тестовый сервер (см. §8).

### Сборка из исходников

```bash
cargo build --release -p ld2-client -p ld2-mock-server
./target/release/ld2-client          # клиент
./target/release/ld2-mock-server     # мок-сервер (ws://127.0.0.1:24817/ws)
```

Требуется стабильный Rust (см. `rust-toolchain.toml`).

### Первый запуск

1. Запустите мок-сервер (или подключитесь к реальному серверу в настройках).
2. Запустите клиент — откроется окно входа.
3. Демо-аккаунты мока: **`demo/demo123`** (персонаж «Ким») и
   **`demo2/demo123`** (персонаж «Астра» — второй клиент для проверки
   чата/группы/сделок).

Токен сохраняется в системную ключницу (keyring) — повторный вход не
потребуется до истечения сессии.

## 2. Обзор интерфейса

```
┌──────────────────────────────────────────────────────────────┐
│ ld2 · статус · RTT · [обновление] [язык] [⚙] [Выход]        │ ← шапка
├──────────┬────────────────────────────┬──────────────────────┤
│ Группа   │ Локация: выходы, сущности  │ Лист персонажа:      │
│ Ресурсы  │ (клик — цель, ПКМ — меню)  │ Навыки · Атрибуты ·  │
│ История  │                            │ Инвентарь · Статусы ·│
│          │                            │ Квесты · Профессии · │
│          │                            │ Гильдия              │
├──────────┴────────────────────────────┴──────────────────────┤
│ Hotbar: руны · свитки/зелья · «Мощный удар»                  │
├──────────────────────────────────────────────────────────────┤
│ Чат: [каналы] история · фильтр · ввод                        │
│ Лог мира: цвета по типу события                              │
└──────────────────────────────────────────────────────────────┘
```

- **Шапка** — статус соединения, RTT, бейдж обновления, язык (RU/EN),
  настройки (⚙), выход.
- **Левая колонка** — группа (ФР-14), HP/mp/пул опыта, история
  посещённых локаций.
- **Центр** — текущая локация: выходы (Alt+клик или Alt+стрелка),
  список сущностей (клик — цель, ПКМ — контекстное меню: осмотр,
  атаковать, пригласить, торговать), подробности осмотра.
- **Правая колонка** — лист персонажа (6 вкладок; инвентарь —
  отдельное окно рюкзака, см. ниже).
- **Внизу** — hotbar, панель чата и журнал мира.

## 3. Персонаж и рост

- **Навыки и опыт**: убийства и крафт дают XP навыков; очки пула
  (`xp_pool`) вкладываются в навык вручную (вкладка «Навыки» →
  «Вложить»). Пул пополняется квестами.
- **Атрибуты** — STR/INT и производные статы (бонусы экипировки в
  инвентаре показываются в описании предмета).
- **Инвентарь**: 40 слотов; экипировка — 15 слотов (шлем, наплечники,
  поручи, перчатки, доспех, поножи, сапоги, плащ, 2 кольца, амулет,
  правая/левая рука, 2 артефакта). Двуручное оружие (посох, лук,
  двуручный меч) занимает обе руки и **блокирует левую ячейку**;
  правила по классам: воин — щит и меч либо двуручник (без посоха и
  лука), лучник — только луки, маг — только посох. ЛКМ/ПКМ — меню
  (использовать, надеть, выбросить, улучшить, инкрустировать,
  осмотреть).
- **Статусы преступности** — бейджи с обратным отсчётом (server-time),
  журнал нарушений; частичное сложение сроков считает сервер.
- **Квесты** — журнал с целями/прогрессом, кнопки Взять/Сдать/
  Отказаться, трекер (до 3 квестов) над листом.
- **Профессии** — ранги и XP, обучение из каталога, рецепты
  (нехватка ингредиентов подсвечена красным) и кнопка «Создать».
- **Гильдия** — состав и ранги, журнал, операции (создать/вступить/
  выйти/пригласить/исключить/сменить ранг), список гильдий мира.

## 4. Мир и бой

- **Навигация**: Alt+↑↓←→ (по направлениям выходов) или клик по
  выходу. Клавиши ремаппингаются в настройках (§7).
- **Цель**: клик по строке сущности или **Tab** (следующая цель) —
  ремаппится. Цель показана над ресурсами с HP-баром.
- **Атака**: кнопка «Атаковать» (в безопасной зоне скрыта — сервер
  решает), «Отступить/Сбежать» в бою.
- **Магия**: руны посоха (с бейджем зарядов) и свитки — hotbar;
  свитки с целью требуют выбора цели. Кулдаун и мана — из данных
  сервера (клиент не пересчитывает).
- **Смерть**: модалка «Вы погибли» со списком утраченного, респаун в
  деревне (окно закрывается только кнопкой).

> Клиент никогда не пересчитывает серверные правила: шансы, урон,
> blend преступности (`§4.10`) — всё приходит с сервера.

## 5. Чат (ФР-13)

Шесть каналов во вкладках панели чата: **системный, локация, мир
(global), группа, гильдия, шёпот**. Фильтр-строка ищет по тексту и
автору; история — кольцевой буфер (5 000/канал, настраивается),
сбрасывается при смене персонажа.

**Слэш-команды** (ввод с `/`):

| Команда | Действие |
|---|---|
| `/w Имя текст` | шёпот указанному игроку |
| `/r текст` | ответ последнему адресату шёпота (кнопка «Ответить») |
| `/p текст` | в канал группы |
| `/g текст` | в канал гильдии |
| `/scenario …` | админ-сценарии чата (см. §8) |

Неизвестная команда показывается тостом и **не отправляется** как текст.

## 6. Группа, сделки, гильдии

- **Группа**: «Создать группу» в виджете слева; приглашение — через
  ПКМ игрока «+ Пригласить» или из окна приглашения (Принять/
  Отклонить). Лидер исключает участников; выход передаёт лидерство.
- **Сделка**: ПКМ игрока «Торговать» (обе стороны должны быть в одной
  локации — сервер проверяет). Окно: две колонки (я/партнёр), добавление
  предметов, золото, «Зафиксировать»/«Принять»/«Отмена». Каждое изменение
  поднимает **версию** сервера; устаревшая версия отклоняется
  (`E_TRADE_STALE`) — окно перерисовывается по новому состоянию.
  Итоговая оценка стоимости и предупреждение о безвозвратности —
  в шапке окна.
- **Гильдия** — вкладка в листе (см. §3).

## 7. Настройки (кнопка ⚙)

| Раздел | Описание |
|---|---|
| Тема | тёмная / светлая (палитра адаптируется) |
| Шрифт | масштаб 1.0–1.4 (минимум 12 px — НФР) |
| История чата | лимит на канал, 500–10 000 |
| Уведомления | системные: смерть, приглашения, сделка, шёпот, улучшение |
| Сервер | адрес `wss://…`; в release-сборке внешний `ws://` запрещён (только localhost) |
| Горячие клавиши | ремаппинг: нажмите на строку и задайте сочетание |

Все настройки, а также открытая вкладка листа и свёрнутость пати-виджета,
сохраняются в `config.toml` (каталог конфигурации указан внизу окна
настроек) и переживают перезапуск.

**Клавиши по умолчанию**: `Alt+↑↓←→` — навигация, `Tab` — следующая
цель, `Enter` — отправка чата, `Esc` — закрытие окон, `C` — окно
персонажа, `I` — окно рюкзака.

## 8. Тестовый сервер (мок)

```bash
ld2-mock-server --bind 127.0.0.1:24817   # по умолчанию
```

Два клиента независимы: входите `demo/…` и `demo2/…` — можно проверять
шёпот, группу и сделки между окнами.

### Админ-сценарии чата

Сценарии вводятся **обычным сообщением чата** (префикс `/scenario `) и
выполняются от имени вошедшего персонажа — отдельных прав не требуется,
поэтому на публичном сервере это следует учитывать (dev-инструменты
тестового окружения). Неизвестный сценарий отклоняется тостом и **не
отправляется** как текст.

| Команда | Эффект |
|---|---|
| `/scenario give <def_id>` | выдать предмет по контенту (стак или инстанс), напр. `give potion_heal` |
| `/scenario gold <n>` | начислить `n` золота (стак монет) |
| `/scenario crime <kind>` | нарушение штатным потоком (§10): смешение срока, статус, журнал; `kind` — `murderer`, `marauder`, `thief`, `criminal` |
| `/scenario kit` | тестовый набор рюкзака: экипировка/расходники/руны с улучшениями, 500 золота |
| `/scenario test` | тестовый рюкзак и прогресс (M18/F45): **100 позиций** — все определения контента по кругу (расходники стаками, экипировка инстансами), все раритеты; валюты (1000 золота + 100 `gem_str`); **уровень 10** и **1000 очков опыта**. Счёт позиций добирается инстансами до 100; повторный запуск сливает стаки и добавляет только инстансы. Внимание: лимит рюкзака (`gameplay.inventory.slots`) команда не проверяет — при лимите меньше 100 подбор новых предметов будет отклонён (`E_INVENTORY_FULL`), пока рюкзак не разгрузят |
| `/scenario skillxp <skill_id> [xp]` | заполнить шкалу навыка — по умолчанию ровно до 100 % (смоук обучения у тренера); с аргументом `xp` ставит указанное значение |
| `/scenario death` | смерть персонажа: потеря лута → респаун в спавне |

Пример смоука обучения: `/scenario skillxp sword` → шкала «Владение
мечом» заполнена → в диалоге Старосты реплика «Чему ты можешь научить?»
→ панель обучения (список навыков и цена) → «Обучить». Если шкала не
полна, нет очков опыта, золота или предметов — сервер отвечает ошибкой
с причиной (`E_SKILL_NOT_READY`, `E_XP_POOL`, `E_INGREDIENTS`,
`E_NO_TRAINER`…), она показывается тостом.

**Примечание:** команды `upgrade_fail` и `stress`, перечисленные в старых
версиях руководства, относились к мок-серверу и в `ld2-server` не
поддерживаются.

## 9. Диагностика и обновления

- **Логи**: `<каталог данных>/logs/ld2.log` (daily, без секретов);
  детали — `RUST_LOG=debug`.
- **Нет соединения**: проверьте адрес сервера в настройках; в
  release-сборке нужен `wss://` (localhost — исключение).
- **Обновления**: при старте клиент проверяет GitHub Releases (не
  блокирует запуск) — зелёный бейдж в шапке открывает страницу релизов.
  Если сервер требует более новую версию (`min_client`), появится
  предупреждение — обновитесь.
- **Ключница**: токены хранятся в системном keyring; «Выход» отзывает
  токен, смена сервера в настройках — нет (токены привязаны к адресу).
