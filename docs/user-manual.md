# ld2 — руководство пользователя

Настольный клиент текстовой онлайн-MMORPG **ld2** (Rust, gpui + Ely).
Версия документа соответствует состоянию **v0.22.0 + M24–M27** (релиз v0.22.0, вехи M24–M27 — в v0.23.0+).

---

## 1. Установка и запуск

### Готовые сборки (релизы GitHub)

| ОС | Артефакт | Запуск |
|---|---|---|
| Windows 10+ | `ld2-<версия>-windows-x86_64.zip` | распаковать, запустить `ld2-gpui.exe` |
| macOS 12+ | `ld2-<версия>-macos.dmg` (universal) или `-macos-universal.tar.gz` | перетащить `ld2.app` в Applications |
| Linux (glibc 2.31+) | `ld2-<версия>-linux-x86_64.tar.gz` или `ld2-<версия>_amd64.deb` | распаковать / `dpkg -i`, запустить `ld2-gpui` |

Рядом с артефактами публикуются `SHA256SUMS-*.txt`. Сервер в клиентский артефакт **не входит** —
он разворачивается отдельно (см. §8). Редактор контента `ld2-editor` собирается CI отдельным
артефактом (для контент-мейкеров).

### Сборка из исходников

```bash
# клиент (gpui; бинарь ld2-gpui)
cargo run -p ld2-client

# редактор контента (gpui; бинарь ld2-editor)
cargo run -p ld2-editor

# сервер (см. §8; PostgreSQL + server.toml)
cp crates/ld2-server/server.example.toml server.toml
cargo run -p ld2-server -- --config server.toml
```

Требуется стабильный Rust из `rust-toolchain.toml` (1.100.0).

### Первый запуск

1. Запустите сервер (§8) или подключитесь к существующему в настройках клиента.
2. Запустите клиент — откроется окно входа.
3. Зарегистрируйте аккаунт (email + пароль) или войдите; создайте персонажа
   (имя + профиль: Воин / Вор / Маг).
4. Токен сохраняется в системную ключницу (keyring) — повторный вход не потребуется
   до истечения сессии или выхода.

## 2. Обзор интерфейса

```
┌───────────────────────────────────────────────────────────────────────┐
│ ld2 · статус · RTT · [карта] [админ]* [⚙] [язык] [аккаунт/выход]     │ ← шапка
├──────────────┬──────────────────────────────────────┬─────────────────┤
│ Группа       │ Локация: описание, выходы, сущности  │ Карта (граф)    │
│ Ресурсы,     │ (клик — цель, ПКМ — меню)            │                 │
│ руны, баффы  │                                       │ Трекер квестов  │
│ Действие     │                                       │                 │
├──────────────┴──────────────────────────────────────┴─────────────────┤
│ Чат (каналы, история, ввод) — 20 % высоты игрового поля               │
└───────────────────────────────────────────────────────────────────────┘
```

- **Шапка** — статус соединения, RTT, бейдж обновления, кнопка карты, настройки (⚙),
  язык (RU/EN), кнопка аккаунта/выхода; у администраторов — кнопка админ-панели.
- **Левая колонка (20 %)** — группа, шкалы ХП/ресурса, индикаторы рун и баффов,
  единый прогресс-бар действия (заточка, инкрустация, разделка).
- **Центр** — текущая локация: описание, выходы списком (стрелка — направление выхода),
  списки игроков/мобов/трупов/объектов (клик — цель, ПКМ — контекстное меню),
  подробности осмотра.
- **Правая колонка (20 %)** — компактная карта-граф окрестности и трекер квестов.
- **Внизу** — чат (приклеен к низу, без вкладок; каналы переключаются в его шапке).

Окна-попапы (одновременно можно держать несколько): **персонаж** `C`, **рюкзак** `I`,
**профессии** `P`, **карта мира** `M`, окно подятия (ЛКМ по трупу/сундуку), настройки,
админ-панель (только `role=admin`). Закрытие — `Esc`, крестик или клик мимо.

## 3. Персонаж и рост

- **Навыки и опыт**: убийства, крафт и добыча дают XP навыков; очки пула (`xp_pool`)
  вкладываются вручную (окно персонажа → «Навыки» → «Вложить»). Пул пополняется квестами.
  Уровень персонажа растёт по серверной кривой; 16 производных характеристик считает сервер.
- **Атрибуты** — STR/INT и производные статы; бонусы экипировки видны в описании предмета.
- **Инвентарь**: 20 базовых ячеек + 4 общих слота под сумки и 3 специальных
  (реагенты, колчан, ключница) до 100+ ячеек суммарно, стаки,
  вкладки-группы типов, нижняя строка валюты (деньги — предметы-монеты). Экипировка —
  отдельные слоты (голова, плечи, руки, торс, ноги, обувь, плащ, кольца, амулет, руки,
  артефакты); двуручное оружие занимает обе руки.
  ЛКМ/ПКМ — меню (использовать, надеть, выбросить, улучшить, инкрустировать, осмотреть).
  Персональные предметы (например, «Кирка мастера» и «Лампа шахтера») нельзя
  передавать в сделке; при выбросе они уничтожаются, а не падают на землю.
- **Сумки** (M28): панель под вкладками рюкзака и иконки слотов в статус-баре справа
  (левее счётчика занятости) — наведите на иконку, чтобы увидеть название сумки, её
  вместимость и сколько занято; пустой слот показан иконкой-заглушкой, клик открывает
  рюкзак на этой сумке. Четыре общих слота плюс три специальных — под сумку реагентов,
  колчан и ключницу: в них встаёт только сумка нужного вида (иначе «сумка не для этого
  слота»). Стартовые «Походные рюкзаки» дают по 20 ячеек; из контента доступны
  8/12/16-слотовые, «Сумка реагентов» (14, травы/руда/дерево/кожа/мясо и т. п.),
  «Колчан» (10, только стрелы) и «Ключница» (8, только ключи). Перетащите сумку из
  вкладки «Сумки» на слот панели, чтобы надеть, и обратно — чтобы снять; клик по слоту
  открывает содержимое. По умолчанию под рюкзаком показаны разделы **всех** надетых
  сумок; в настройках это поведение можно выключить («Показывать все сумки»).
  Предметы переносятся перетаскиванием на раздел «Рюкзак» или в
  содержимое сумки; непустую сумку снять нельзя. Сумка может принимать только
  определённые типы предметов (они написаны в заголовке сумки). При смерти теряется
  содержимое инвентаря и сумок, но сами надетые сумки остаются.
- **Заточка и камни**: улучшение (+N) с превью и правилами провала; камни заточки —
  расходник; инкрустация рун и самоцветов в сокеты оружия/брони.
- **Статусы преступности** — бейджи с обратным отсчётом (server-time), журнал нарушений;
  частичное сложение сроков считает сервер.
- **Квесты** — журнал с целями/прогрессом, кнопки Взять/Сдать/Отказаться, трекер
  (до 3 квестов) в правой колонке.
- **Профессии** — отдельное окно (`P`): только изученные, основные по карточке (лимит 2),
  две шкалы (уровень 0–250 и ранг 1–5), обучение у тренера, рецепты и кнопка «Создать»,
  сброс профессии.
- **Гильдия** — состав и ранги, журнал, операции (создать/вступить/выйти/пригласить/
  исключить/сменить ранг), список гильдий мира.

## 4. Мир и бой

- **Навигация**: `Alt+↑↓←→` (по направлениям выходов) или клик по выходу.
  Клавиши ремаппируются в настройках; карта — только наведение (переходы прежними способами).
- **Цель**: клик по строке сущности или `Tab` (следующая цель) — ремаппится.
  Цель показана над ресурсами с HP-баром; у мобов — прогресс-бар атаки, у босса — череп,
  фаза и каст («готовит: …»).
- **Атака**: кнопка «Атаковать» (в безопасной зоне скрыта — решает сервер),
  «Отступить/Сбежать» в бою.
- **Магия**: руны в любом надетом предмете с сокетами (заряды) и свитки — панель действий
  (`1`–`6`), глобальный кулдаун 1 с. Руна чужого класса недоступна. Кулдаун и мана —
  из данных сервера (клиент не пересчитывает).
- **Эффекты**: стан (окно с прогресс-баром, команды блокируются), немота (нет магии),
  ослепление (нет атак).
- **Смерть**: модалка «Вы погибли» со списком утраченного, респаун в точке возрождения
  (надетые сумки остаются, теряется только их содержимое — M28)
  (деревня или `[world] respawn_location_id`); окно закрывается только кнопкой.
- **Трупы и лут**: ЛКМ по трупу — окно подятия (лут + «Внутри», рюкзак справа,
  «Забрать»/«Взять всё», drag/двойной клик); «Снять шкуру»/«Освежевать» — при изученной
  профессии; сундуки открываются тем же окном.

> Клиент никогда не пересчитывает серверные правила: шансы, урон, blend преступности —
> всё приходит с сервера.

## 5. Чат (ФР-13)

Шесть каналов: **системный, локация, мир (global), группа, гильдия, шёпот**.
Фильтр-строка ищет по тексту и автору; история — кольцевой буфер (5 000/канал,
настраивается), сбрасывается при смене персонажа. Журнал локации — исчезающие строки
(`journal_ttl_s`, по умолчанию 30 с).

**Слэш-команды** (ввод с `/`):

| Команда | Действие |
|---|---|
| `/w Имя текст` | шёпот указанному игроку |
| `/r текст` | ответ последнему адресату шёпота (кнопка «Ответить») |
| `/p текст` | в канал группы |
| `/g текст` | в канал гильдии |
| `/scenario …` | сценарные команды (только `role=admin` или при `server.allow_scenario`) |

Неизвестная команда показывается тостом и **не отправляется** как текст.

## 6. Группа, сделки, гильдии

- **Группа**: «Создать группу» в левой колонке; приглашение — ПКМ игрока «+ Пригласить»
  или из окна приглашения (Принять/Отклонить). Лидер исключает участников; выход передаёт
  лидерство.
- **Сделка**: ПКМ игрока «Торговать» (обе стороны должны быть в одной локации — сервер
  проверяет). Окно: две колонки (я/партнёр), добавление предметов, золото,
  «Зафиксировать»/«Принять»/«Отмена». Каждое изменение поднимает **версию** сервера;
  устаревшая версия отклоняется (`E_TRADE_STALE`) — окно перерисовывается по новому
  состоянию. Итоговая оценка стоимости — в шапке окна.
- **Гильдия** — окно персонажа (см. §3).

## 7. Настройки (кнопка ⚙)

| Раздел | Описание |
|---|---|
| Тема | тёмная / светлая (палитра адаптируется) |
| Шрифт | масштаб (минимум 12 px — НФР) |
| История чата | лимит на канал, 500–10 000 |
| Уведомления | системные: смерть, приглашения, сделка, шёпот, улучшение |
| Сумки | «Показывать все сумки» — в рюкзаке разделы всех надетых сумок (включено по умолчанию); выключите, чтобы открывать по одной |
| Сервер | `wss://`-адрес (release: внешний `ws://` запрещён, кроме localhost); поле **домена** для discovery через `https://<домен>/.well-known/ld2.json` |
| Горячие клавиши | ремаппинг: нажмите на строку и задайте сочетание |

Все настройки, открытая вкладка листа и свёрнутость пати-виджета сохраняются в `config.toml`
(каталог конфигурации указан внизу окна настроек) и переживают перезапуск.

**Клавиши по умолчанию**: `Alt+↑↓←→` — навигация, `Tab` — следующая цель, `Enter` — отправка
чата, `Esc` — закрытие окон, `C` — персонаж, `I` — рюкзак, `P` — профессии, `M` — карта,
`1`–`6` — панель действий.

## 8. Локальный сервер, админ-инструменты и редактор

### Сервер

```bash
cp crates/ld2-server/server.example.toml server.toml   # правки database.url и др.
docker compose up --build -d
curl http://127.0.0.1:24817/healthz                   # → 200 ok, заголовок x-ld2-content-version
```

PostgreSQL поднимается контейнером; миграции применяются автоматически. Контент —
`content/*.json` (8 файлов); сервер замечает правки каталога сам (hot reload, `content_poll_s`)
или по `SIGHUP`/`cmd/admin.content.reload`; `ld2-server seed` применяет контент в БД.

### Админ-панель (только `role=admin`)

Кнопка в шапке открывает каталог всех предметов (поиск, группы), выдачу/удаление в свой
рюкзак, рюкзак другого игрока по имени, лут трупа/монстра, сундук и магазин; режим бога
(неуязвимость) — тумблер в шапке окна. Все операции проходят серверные гейты и аудит.

Роль администратора назначается в БД сервера (`accounts.role = 'admin'`).

### Сценарные команды чата

Выполняются обычным сообщением `/scenario …` **только для админа** или при
`server.allow_scenario` (dev/тесты). Неизвестный сценарий отклоняется тостом и не
отправляется как текст.

| Команда | Эффект |
|---|---|
| `/scenario give <def_id>` | выдать предмет по контенту (стак или инстанс), напр. `give potion_heal` |
| `/scenario gold <n>` | начислить `n` золота (стак монет) |
| `/scenario crime <kind>` | нарушение штатным потоком: смешение срока, статус, журнал; `kind` — `murderer`, `marauder`, `thief`, `criminal` |
| `/scenario kit` | тестовый набор рюкзака: экипировка/расходники/руны с улучшениями |
| `/scenario skillxp <skill_id> [xp]` | заполнить шкалу навыка (по умолчанию до 100 %) |
| `/scenario jump <location_id>` | телепорт в засеенную локацию (ад-карта не связана выходами) |
| `/scenario death` | смерть персонажа: потеря лута → респаун |

### Редактор контента

`ld2-editor` (gpui + Ely) — правка `content/*.json` с валидацией, undo/redo, атомарным
сохранением и картой-полотном; `Ctrl+P` — палитра перехода, `F1` — помощь, кнопка «Seed»
применяет контент на сервере. Подробнее — [`crates/ld2-editor/README.md`](../crates/ld2-editor/README.md).

## 9. Диагностика и обновления

- **Логи**: `<каталог данных>/logs/ld2.log` (daily, без секретов); детали — `RUST_LOG=debug`.
- **Нет соединения**: проверьте адрес/домен сервера в настройках; в release-сборке нужен
  `wss://` (localhost — исключение).
- **Обновления**: при старте клиент проверяет GitHub Releases (не блокирует запуск) —
  бейдж в шапке открывает страницу релизов. Если сервер требует более новую версию
  (`min_client`), появится предупреждение — обновитесь.
- **Ключница**: токены хранятся в системном keyring; «Выход» отзывает токен, смена сервера
  в настройках — нет (токены привязаны к адресу).
