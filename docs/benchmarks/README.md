# Бенчмарки

Локальные балансные отчёты. Сами отчёты — артефакты запуска и в git не
коммитятся; в репозитории лежат только скрипты и эта инструкция.

## Рудные жилы

Считает шанс камня за успешную добычу и за попытку, ожидаемое число
камней с полной жилы, распределение `P(0..N)`, «1 камень в N попыток»
и камни/час на одной жиле. Учитывает «Кирку мастера» и «Лампу
шахтёра».

**macOS / Linux:**

```bash
scripts/bench-ore-gems.sh
# только напечатать, без записи:
scripts/bench-ore-gems.sh --stdout
```

Нужны `bash`, `jq` и `awk` (`brew install jq` / `apt install jq`).

**Windows:**

```bat
scripts\bench-ore-gems.bat
```

BAT вызывает встроенный PowerShell; дополнительных зависимостей нет.

Оба скрипта пишут `docs/benchmarks/ore-gems.md`. Файл добавлен в
`.gitignore` — это локальный отчёт. Допущения и формулы описаны в
самом отчёте и в [`../professions.md`](../professions.md).
