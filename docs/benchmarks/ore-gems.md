# Бенчмарк рудных жил — камни (M39)

Сгенерировано `scripts/bench-ore-gems.py` по `content/locations.json` и `server.example.toml`.

## Допущения

- уровень профессии = требуемому уровню жилы: гейт пройден, добыча 2 с, шанс успеха 95 %;
- провал добычи (5 %) тоже списывает 1 запас жилы, но камня не даёт;
- одна попытка = одна единица запаса; камень — 1 шт. за успешный бросок;
- «Камней/час» — одна жила: полный запас × 2 с + средний респавн; без переходов между жилами;
- для руды взята самая ёмкая жила (у олова в лесу есть жила с запасом 2);
- инструменты: кирка ×2, лампа +2 п.п. (`mining_master_gem_mult` / `mining_lamp_gem_bonus`).
