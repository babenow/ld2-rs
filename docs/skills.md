# Навыки и профессии — GDD ld2

**Документ:** гейм-дизайн-описание контента. **Статус:** утверждён — открытые вопросы §10 закрыты (решения 2026-11-03, `PLAN-M0.md` §1).
**Связи:** [`tz.md`](./tz.md) ФР-04 (навыки/опыт), ФР-08 (профессии); [`protocol.md`](./protocol.md) — контракт полей; `ld2-mock-server` — потребляет списки из этого файла как фикстуры.

> конфигурацию в своей БД/конфиге; клиент **никогда** не считает эффекты — только рендерит то,
> что прислал сервер (см. `protocol.md` §2.4, §10).

## 1. Атрибуты персонажа (базовые)

| ID | Атрибут | Что определяет | Старт (пример) |
|---|---|---|---|
| `str` | Сила | физ. урон, тяжёлая броня, носимый вес, требования воинских навыков | 10 |
| `dex` | Ловкость | уклонение, крит, скрытность, лёгкая броня, требования воровских навыков | 10 |
| `vit` | Выносливость | макс. HP, сопротивления, выживание в опасных зонах | 10 |
| `int` | Интеллект | эффект магических школ, требования Арканы/Профессий-интеллектуалов | 10 |
| `cha` | Харизма | социальные навыки, цены торговли, требования Командования | 10 |

Атрибуты растут сервером (по квестам/настоящим требованиям рангов) — не путать с навыками.
**Ресурс маны (mp)** — введён (решение D4): `mp: {cur, max}`, максимум растёт с `int` и рангом `arcana` (см. §2.4); свитки ману не тратят, активные способности воина — тоже.

## 2. Модель опыта и рангов

### 2.1 Два потока опыта

| Поток | Источник | Назначение | Контракт |
|---|---|---|---|
| **Опыт навыка** (skill XP) | прямое действие: убийство нужным оружием/школой, успешное применение навыка | прогресс ранга конкретного навыка | `evt/char/xp { skill_id, amount, skill_xp, rank }` |
| **Очки опыта** (XP-пул) | **квесты** (награда), события/достижения | **повышение ранга у тренера в диалоге** — только при шкале навыка 100 % (M18/F44) | `cmd/skill.train { entity_id, skill_id }` → `evt/char/xp { …, pool_left }` |

Так выполнено требование ТЗ: «очки опыта зарабатываются квестами и убийствами» — убийства
идут напрямую в релевантный навык, квесты дают пул, который игрок вкладывает сам.

### 2.2 Пороги и потолки (серверные константы, §10)

```
xp_to_next(rank) = round( BASE_XP × GROWTH^rank )       # BASE_XP=120, GROWTH=1.32
пример: r0→120, r5→636, r10→2148, r20→24645
```

- Ранг навыка: `0 … RANK_MAX (30)`.
- **Гейты по атрибутам:** ранг 10 требует атрибут 12, ранг 20 — 18, ранг 30 — 25 (сервер
  возвращает `E_REQUIREMENT_ATTR` при попытке вложить).
- Потеря при смерти: **только лут** (ТЗ §3.6). Опыт навыков и XP-пул **не теряются** — осознанное
  решение, чтобы смерть не била в прогресс.

### 2.3 Множители убийств (relevance)

`xp_kill = (8 + difficulty × 6) × relevance`, где `difficulty` — серверная сложность монстра 1..10.

| Relevance | Кому | Пример |
|---|---|---|
| 100% | навык действия (оружие/школа) | убил мечом → `sword` |
| 40% | смежная защита (получал урон) | `evasion` / `armor_*` в бою |
| 20% | второстепенная | `bestiary` при первом убийстве вида |

Квестовый пул: обычный квест 50–150, цепочка 500–1500, ежедневный ~100 (баланс-примеры).

### 2.4 Ресурс маны (mp) — решение D4 (ADR-002)

- `mp: { cur, max }` у персонажа; `mp_max = 20 + int × 4 + arcana × 5` (конфиг сервера, баланс-пример).
- **Каст руны** тратит **ману И заряд руны** (двойной ресурс): мана ограничивает залп, заряды — непрерывное использование; заряды восстанавливаются маслом алхимика.
- **Свиток** — одноразка, ману **не тратит** (сам свиток и есть расходник).
- **Активные способности воина** (§4) — только кулдаун, ману не тратят.
- Реген: вне боя — быстро (~полный бар за 30–60 с), в бою — медленный тик (конфиг `[mana]` в §8).
- Зелья маны — продукция Алхимика (§5.2); их наличие — основной источник «второго бара» в затяжном бою.

## 4. Активные способности (hotbar, `cmd/skill.use`)

Активки отдельны от пассивных рангов: открываются требованиями, применяются с кулдауном
(`evt/combat/cooldown`), **ману не тратят** (D4). Маг идёт в бой со свитками/рунами, воин — с активками.

| ID | Способность | Открывается | Эффект | Кулдаун |
|---|---|---|---|---|
| `power_strike` | Мощный удар | `sword` 5 | ×1.8 урона одной цели | 8 с |
| `cleave` | Раскол | `axe` 8 | ×1.4 цели, 20% оглушения | 12 с |
| `volley` | Град стрел | `bow` 12 | ×1.5 по цели, игнорирует часть брони | 10 с |
| `ambush` | Засада | `stealth` 10 + `dagger` 5 | ×2.5 первый удар из скрытности | 30 с |
| `shield_bash` | Удар щитом | `block` 8 | ×1.0 + оглушение цели | 15 с |
| `second_wind` | Второе дыхание | `survival` 15 | лечит 10% макс. HP | 120 с |
| `rally` | Стойкость | `leadership` 10 | +10% урона группе на 20 с | 60 с |

## 5. Профессии

### 5.1 Модель

- **Первичные** (крафт, занимают слот) — лимит `profession_limit` из `evt/session.start` (по умолчанию **2**): Кузнец, Алхимик, Начертатель, Резчик, Портной, Повар.
- **Вторичные** (добыча, слот **не** занимают, открываются квестом/навыком): Травник, Охотник.
- **Изучение:** у NPC-учителя (городская гильдия/мастерская) — `cmd/craft.learn { profession_id }`; стоимость золотом, репутация или квест. Превышение лимита → `E_PROFESSION_LIMIT`.
- **Ранги профессии:** 1…7. XP за успешный крафт: `40 + 25 × ранг_рецепта`; при неудаче — 20% XP (баланс-пример, сервер).
- **Порог ранга:** `profession_xp_to_next(rank) = round(80 × 1.5^rank)`.
- **Рецепт требует:** ранга профессии, иногда навыка/атрибута, **станка в локации**, **инструмента** (предмет в инвентаре), ингредиентов, времени (`time_s`).
- Крафт доступен из вкладки «Профессии» (ФР-08); клиент показывает нехватку ингредиентов красным, итог решает сервер (`E_INGREDIENTS` / `E_STATION_REQUIRED` / `E_TOOL_MISSING`).

### 5.2 Список профессий

| ID | Профессия | Тип | Что производит | Станок / инструмент | Сырьё | Связи |
|---|---|---|---|---|---|---|
| `blacksmith` | Кузнец | первичная | мечи/топоры/копья, тяжёлая броня, щиты, пластины и заклёпки (материалы для улучшения) | горн + наковальня; молот | руда (`mining`), слитки, кожа (`hunter`) | рецепты брони требуют `armor_heavy` 5 |
| `alchemist` | Алхимик | первичная | зелья HP и **зелья маны**, баффы, яды, **масла для восстановления зарядов рун**, реагенты | алхимический стол; колба | травы (`herbalist`), флаконы у торговца | масло → заряды рун, зелья → mp (§2.4) |
| `scribe` | Начертатель | первичная | **свитки и руны-заготовки**, чертежи/карты | стол начертателя; перо | пергамент, **чернила (алхимик)**, пигмент | требует `arcana` 5, `int` 12 |
| `woodcarver` | Резчик | первичная | **посохи** (в т.ч. с 2–3 сокетами), луки, стрелы | верстак; резец | древесина (`woodcutting`), смола | напрямую питает систему магии ФР-09 |
| `tailor` | Портной | первичная | лёгкая броня, одежда, сумки, шкуряная обувь | швейный верстак; игла | шкуры (`hunter`), нити | синергия с `armor_light` |
| `cook` | Повар | первичная | еда с длительными баффами (сила/реген/устойчивость), походные наборы | костёр/кухня; казан | мясо (`hunter`), травы (`herbalist`), специи | еда — единственный постоянный источник регена вне боя |
| `herbalist` | Травник | вторичная | сбор трав и грибов (доступ к узлам в поле), венки/повязки | без станка (в поле) | — | питает Алхимика и Повара |
| `hunter` | Охотник | вторичная | разделка туш: мясо, шкуры, рога, трофеи | без станка (в поле); нож | трупы зверей | питает Кузнеца/Портного/Повара |

### 5.3 Цепочки сырья

```
Шахта: руда (mining) ──[горн]──► слитки ──[Кузнец]──► оружие, броня, материалы улучшения
Лес:   древесина (woodcutting) ──[верстак]──► Резчик ──► посохи (сокеты!), луки, стрелы
Поле:  травы ─[Травник]─► [Алхимик] ─[стол]─► зелья, масла рун
                                      └─чернила─► [Начертатель] ─[стол]─► руны, свитки
Зверь: мясо/шкуры ─[Охотник]─► [Повар] ─[костёр]─► еда-баффы
                                   └─► [Портной] ─[верстак]─► лёгкая броня, сумки
```

Замыкание: Кузнец кладёт в улучшение предметов свои пластины, Резчик — редкие посохи для рун
Начертателя, Алхимик заряжает руны маслом: профессии не изолированы друг от друга и стимулируют
обмен через торговлю (ФР-15).

### 5.4 Структура рецепта (payload `cmd/craft.recipes`)

```json
{
  "id": "rec_sword_iron",
  "name": "Железный меч",
  "profession": "blacksmith", "rank": 3,
  "station": "forge",                    // станок, который должен быть в локации
  "tool": { "item_type": "hammer" },     // инструмент в инвентаре
  "requires": { "attr": { "str": 10 }, "skill": { "armor_heavy": 0 } },
  "inputs": [ { "type": "ingot_iron", "qty": 3 }, { "type": "wood_oak", "qty": 1 } ],
  "time_s": 20,
  "xp": { "profession": 85 },
  "output": { "type": "sword_iron", "qty": 1, "quality_by": "rank" },
  "station_label": "Кузница (город)"     // для UI
}
```

## 6. UI-требования (клиент, ФР-04/ФР-08)

**Вкладка «Навыки»:**
- группы сворачиваются (A–F), у каждой строки: ранг `12/30`, прогресс-бар `xp/xp_to_next`, эффект текущего и «что даёт следующий ранг»;
- вверху — XP-пул (M18/F44: вложение из пула убрано — очки тратятся на
  повышение ранга у тренера в диалоге); под шкалой, заполненной на 100 %,
  подсказка «возможно повышение ранга»;
- гейты: недоступное вложение с пометкой «нужен `str` 12» (текст ошибки сервера), серые строки закрытых навыков с условием открытия;
- активные способности — отдельный блок со списком условий открытия и кулдаунов (бейдж-таймер).

**Вкладка «Профессии»:**
- карточки: ранг, XP-бар, тип (первичная/вторичная), учитель и локация;
- рецепты: фильтр «могу собрать сейчас» (клиентская сверка инвентаря — итог сервера), пометки: «нужен станок: Кузница (город)», «нет инструмента: Молот», «не хватает: 2× железный слиток» (красным);
- бейдж «новый рецепт» при повышении ранга; крафт с прогрессом `time_s` (можно закрыть окно, итог — `evt/craft/result`).

**Синхронизация:** сервер — истина. Клиент хранит `xp_pool` из `evt/char/xp.pool_left` и список
профессий из `cmd/craft.list`/`evt/craft/profession`; всё пересчитывается после снапшота.

## 8. Балансировочные константы (конфиг сервера)
