# ADR-003: Контент-решения v1 (профили персонажей, статусы, слоты, уведомления, локализация, карта)

**Дата:** 2026-11-03 · **Статус:** принято · **Связано:** `docs/tz.md` ФР-02, ФР-11, ФР-18, §14; `docs/skills.md` §8, §10; `PLAN-M0.md` D3, D5–D10

## Контекст

Открытые вопросы ТЗ §14 и `skills.md` §10, закрытые перед стартом M0. Зафиксированы здесь, чтобы
не перетирать ТЗ/контракт в будущем без явного нового ADR.

## Решения

| # | Тема | Решение |
|---|---|---|
| D3 | Создание персонажа | **Имя + стартовый профиль** (Воин/Вор/Маг — наборы стартовых навыков); без рас и классов в v1. `cmd/char.create { name, profile }`, состав профилей — capability-данные сервера |
| D5 | Статус «Вор» (`thief`) | **Включён в мок**: карманная кража у игроков разрешена, 3 статуса в `crime.kinds` (Убийца/Мародёр/Вор); клиент рендерит generic по title/severity |
| D6 | Слоты персонажей | мок: `char_slot_limit = 8`; поле остаётся динамическим (сервер может менять без релиза клиента) |
| D7 | OS-уведомления | feature-flag `desktop.notify`; по умолчанию 4 события: смерть персонажа, приглашение в пати/сделку, whisper, результат улучшения предмета |
| D8 | Локализация | **P1:** таблицы `ru/en` вводятся с M0 (`l10n`), полный перевод — M9 (перед v1.0) |
| D9 | Карта-граф | **Не в v1:** история посещённых локаций + быстрые переходы; визуальный граф — v1.1 (backlog `ROADMAP.md`) |
| D10 | Прочие дефолты | константы преступности `k=0.5, T_MAX=604800, murderer=21600, marauder=7200`; чужие бои — только текст локации; гильдейский банк вне v1; состав 28 навыков / 8 профессий; `profession_limit=2`; `dark` — вне M7; деградации навыков нет |

## Последствия

- M2 (персонажи) проектируется под мастер «имя + профиль», не под расы/классы.
- M6 включает 3 статуса преступности; `pickpocket` против игроков разрешён в моке.
- `l10n` обязан поддерживать две таблицы с первого коммита (D8).
- Любое изменение этих пунктов — новый ADR + PR `[tz-amend]`.
