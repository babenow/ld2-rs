# ADR-002: Мана как ресурс — двойная модель «мана + заряды рун»

**Дата:** 2026-11-03 · **Статус:** принято · **Связано:** `docs/tz.md` ФР-05, ФР-09; `docs/protocol.md` §5, §6, §8, §9; `docs/skills.md` §1, §2.4, §5.2, §8; `PLAN-M0.md` D4

## Контекст

ТЗ изначально описывало магию через свитки и руны с зарядами, без маны (`mp: null` в контракте).
В ходе обсуждения перед стартом принято решение **ввести ману**. Возник вопрос сосуществования:
заряды рун уже являются расходным ресурсом, и они же — рычаг профессии Алхимика (масла).

## Решение — двойной ресурс

| Источник заклинания | Стоит | Примечание |
|---|---|---|
| **Свиток** | только свиток (одноразка) | ману **не** тратит |
| **Руна в посохе** | **мана + 1 заряд руны** | заряды восстанавливаются маслом алхимика |
| **Активки воина** (`skill.use`) | только кулдаун | мана — чисто магический ресурс |

- `mp: { cur, max }` вместо `mp: null`; `mp_max = 20 + int × 4 + arcana × 5` (конфиг сервера).
- Реген: вне боя быстро (~45 с на полный бар), в бою медленно (~1%/с) — конфиг `magic.mana` в `session.start`.
- Нехватка ресурса: `E_NOT_ENOUGH_MP` (мана) и `E_NO_CHARGES` (заряды) — раздельные коды, клиент
  приглушает иконку с конкретной причиной.
- Зелья маны — продукция Алхимика (`docs/skills.md` §5.2), масла — восстановление зарядов.

## Последствия

- Контракт меняется **аддитивно** (новые поля/коды, wire-`v` остаётся 1): `char.mp`, `magic.mana`,
  `mp_left` в `evt/magic/cast`, `E_NOT_ENOUGH_MP`.
- Баланс: мана ограничивает залп, заряды — непрерывное использование; реген и стоимость кастов —
  баланс-константы сервера (`docs/skills.md` §8).
- UI: mp-бар в панели боя (ФР-05) и листе персонажа; тултип стоимости в hotbar.
