# Профессии — свод данных (M21 «Профессии» + M22 «Снятие шкур»)

Единственный справочный файл по системе профессий: модель прогресса,
цены, источники опыта, команды/wire, контент и механика снятия шкур.
Планы вех — в `plans/PLAN-M21.md`, `plans/PLAN-M22.md`; контракт —
`docs/protocol.md` (§6/§7/§9).

## 1. Модель прогресса (M21)

Две шкалы на каждую изученную профессию (`character_professions`:
`xp`, `rank`, `level`; миграция `0028`):

- **Уровень** `0 … max_level=250` — растёт **автоматически** по XP;
  порог `xp_до_уровня(L) = round(level_xp_base × level_xp_growth^L)` =
  **`round(40 × 1.02^L)`** (каждый уровень дороже на 2 %):
  L0→40, L1→41, L50→108, L100→290, L150→780, L200→2100,
  L249→≈5.5 тыс.; суммарно ~290 тыс. XP до Мастера.
  Остаток XP **переносится** на следующий уровень; на `max_level`
  опыт **перестаёт копиться** (→0).
- **Ранг** `1 … 5` — **только вручную**, границы кратно
  `rank_span=50` уровней: ранг1 = 0–50, ранг2 = 50–100,
  ранг3 = 100–150, ранг4 = 150–200, ранг5 = 200–250.
  Названия: **Новичок, Ученик, Ремесленник, Знаток, Мастер**.
  Повышение:
  1. **у тренера за золото** — `cmd/craft.rank_up`: уровень ≥ границы
     (`E_LEVEL_REQUIRED`), тренер по профессии в локации
     (`E_NO_TRAINER`), цена `round(rank_up_gold_base ×
     rank_up_gold_growth^ранг)` = **`200 × 1.5^ранг`**
     (1→300, 2→450, 3→675, 4→1013 з.);
  2. **наградой задания** — `reward.rank_up: "<profession_id>"` в
     квесте: та же граница уровней, **без золота и тренера**
     (контент: «Волчья беда» → +1 ранг Снятия шкур; сдача
     блокируется `E_LEVEL_REQUIRED`, пока не набрана граница).

Конфиг `[gameplay.professions]`: `level_xp_base=40`,
`level_xp_growth=1.02`, `max_level=250`, `rank_span=50`,
`rank_up_gold_base=200`, `rank_up_gold_growth=1.5`,
`xp_per_craft_base=40`, `xp_per_craft_per_rank=25`, `fail_xp_ratio=0.2`.

## 2. Виды профессий, цены, лимиты

- **Основные (11)**: Травничество (herbalist), Алхимия (alchemist),
  Горное дело (mining), Кузнечное дело (blacksmith), Снятие шкур
  (skinning), Кожевенное дело (leatherworking), Портняжное дело
  (tailor), Начертание (scribe), Лесозаготовка (woodcutting),
  Резчик (woodcarver), Ювелирное дело (jeweler).
- **Дополнительные (3)**: Кулинария (cook), Рыболовство (fishing),
  Лечение (medic) — изучаются **параллельно**, лимит не трогают.
- **Лимит основных: 2** (как в WoW; `profession_limit`, §5).
- **Обучение — дорого**: у тренера маркер `price_profession`
  (`gold_base=500`); навыки — общий маркер `price` (100 з.).
- **Сброс**: `cmd/craft.reset {profession_id}` из окна профессий
  (кнопка с двухшаговым подтверждением) — прогресс теряется, слот
  основной освобождается (`E_PROFESSION`, если не изучена).
- Обучение доступно: окно профессий (демо-селект убран) и
  **панель «Обучение» в диалоге НПС** (`npc.talk → professions[]
  {id, gold}`, кнопка «Изучить» → `cmd/craft.learn`).

## 3. Источники опыта

| Источник | Формула | Что растёт |
|---|---|---|
| Крафт | `40 + 25 × ранг_рецепта` за изделие | **уровень** |
| Добыча ресурсов (`resource.gather`) | `40 + 25 × ранг_профессии` за единицу | **уровень** |
| Снятие шкур (M22, только «Снять шкуру») | `треб_уровень × 20 × множитель` | **уровень** |

Множитель опыта снятия шкур по разнице `diff = уровень персонажа −
требуемый уровень животного`:

| diff | множитель |
|---|---|
| ≤ −10 | **×1.5** |
| −9 … +9 | ×1.0 |
| +10 … +24 | ×0.5 |
| ≥ +25 | **×0** (опыта нет) |

Гейт: животное, чей требуемый уровень выше уровня персонажа **на 25 и
более**, разделать нельзя (`E_LEVEL_REQUIRED`).
«Освежевание» опыта **не даёт** (только лут).

## 4. Wire и команды

- `cmd/craft.learn {profession_id}` → `{profession}` (тренер, лимит,
  оплата500);
- `cmd/craft.rank_up {profession_id}` → `{profession}` (тренер,
  граница, `200×1.5^ранг`);
- `cmd/craft.reset {profession_id}` → `{profession_id}`;
- `cmd/resource.gather {entity_id}` — добыча (инструмент `item_type`,
  ранг `min_rank`, XP → уровень);
- `cmd/corpse.harvest {entity_id, action: skin|gut}` →
  `{action, name}` — разделка (M22, сервер-джоб 5 с);
- `evt/craft/profession {profession: {id, rank, level, xp,
  xp_to_next, extra: {rank_span, rank_up_gold?}}}` — изучение/уровень/
  ранг;
- `evt/harvest/result {entity_id, name, action, ok}` — итог
  разделки (M22);
- ошибки §9: `E_LEVEL_REQUIRED` (граница ранга/гейт25+),
  `E_PROFESSION`, `E_TOOL_MISSING`, `E_NO_TRAINER`,
  `E_PROFESSION_LIMIT`, `E_RANK_CAP`.

## 5. Контент

- `content/professions.json` — состав/названия (14);
- `content/locations.json` → `entities[].trainer` Старины:
  `professions[]` (все 14), `price` (навыки), `price_profession`
  (500); у животных — флаги `harvest: {level, skin, gut}`
  (м_3 Волк: level5; крысы:1; огромная крыса:4);
- `content/quests.json` → `q_wolf_hunt.reward.rank_up = "skinning"`;
- инструменты-предметы (тип = `item_type`): топор/кирка/серп,
  **нож для снятия шкур** (`skinning_knife`);
- UI: окно профессий (`PopupKind::Professions`, кнопка в шапке +
  хоткей «p»): два слота основных (пустые — «Первая/Вторая
  профессия»), ниже всегда три дополнительные (неизученные — пустые
  карточки с названием); две полосы (уровень, граница ранга),
  «Повысить ранг», «Сбросить»; без рецептов и селекта обучения.

## 6. Снятие шкур (M22) — свод механик

- **Условия** (клиент показывает пункты меню, сервер валидирует):
  изучена профессия `skinning`, в инвентаре `skinning_knife`, у
  трупа животного флаги `harvest` (`skin`/`gut`), действие ещё не
  сделано (`skin_done`/`gut_done`), гейт уровней (§3).
- **Пункты меню трупа**: «Снять шкуру» (skin) и «Освежевать» (gut).
- **Таймер**: сервер-джоб **5 с** (персонаж свободен), клиент
  рисует прогресс-бар; по готовности — `evt/harvest/result`
  (журнал: «Вы сняли шкуру с трупа {животное}» /
  «Вы освежевали труп {животное}») + лут в труп +
  `evt/corpse/created` (обновление).
- **Лут**:
  - **Снять шкуру**: бросок **шанса шкуры** (иначе обрезки):
    `шанс_шкуры = min(60%, 1% + 2% × уровень_профессии)` —
    на старте практически невозможно (ур.0→1 %, ур.10→21 %,
    ур.25→51 %, потолок 60 % с ур.30);
  - **качество** (шкура и обрезки) = **ранг профессии 1…5**:
    | ранг | шкура | обрезки |
    |---|---|---|
    | 1 | Шкура | Обрезки шкуры |
    | 2 | Хорошая шкура | Хорошие обрезки |
    | 3 | Отличная шкура | Отличные обрезки |
    | 4 | Превосходная шкура | Превосходные обрезки |
    | 5 | **Великолепная шкура** | Великолепные обрезки |
    Цвета качеств — **своя палитра, не совпадает с цветами
    редкости предметов** (предложение: #7a6a55, #96793f, #b8860b,
    #daa520, #ffd700 — «кожаная» гамма; утвердить на смоук);
  - **крит**: шанс по рангу — р1 5 %, р2 10 %, р3 15 %, р4 20 %,
    р5 25 %; при крите **сверх обычного результата** в лут
    добавляется **+2 шкуры** текущего качества;
  - **Освежевать**: мясо (25 %) либо потроха (75 %) — **в отдельный
    блок «Внутри»** лута трупа (не в общий список).
- **Опыт**: только за «Снять шкуру», формула и множители — §3.
