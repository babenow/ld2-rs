## 2026-11-18

- **Разделка: блок действий и урон** — пока идёт таймер, действия
  мира/развития отклоняются `E_BUSY` (item-команды и информационные
  — исключения, M23 сохранена); урон прерывает разделку: снятие
  шкуры → кожа испорчена (повтор нельзя, без шкуры/опыта),
  освежевание → отмена с повтором; e2e `harvest_blocks_character_actions`,
  docs/professions.md §6, protocol.md (`E_BUSY`).
- **Переключение разделки** — старт на другом трупе разрешён: текущее
  действие прерывается, шкура брошенного трупа портится (gut и skin);
  повтор на том же трупе — `E_COOLDOWN`; клиент гасит бар только по
  итогу своего трупа (`entity_id` в `HarvestProgress`); e2e
  `harvest_switch_to_another_corpse_interrupts_and_ruins`.
- **Единый прогресс-бар** левой колонки: одна сущность `CastProgress`
  (действие · имя, время) для снятия шкур/освежевания, инкрустации и
  заточки; бар инкрустации переехал из-под панели действий; фикс —
  прогресс заточки не был виден (длительность vs epoch-мс в tick).
- **Панель рун и баффы**: кнопки каста — для всей надетой экипировки
  с рунами (был только посох → руна шторма в мече без кнопки);
  тултипы на рунных строках; только руны (без самоцветов);
  индикаторы активных бафов рун с морганием за3 с; тест ярости
  воина (`warrior_rage_accumulates_on_melee`).
- **Индикаторы рун** под ресурсом персонажа: глиф · прогрессбар
  заполнения · N/M (только надетая экипировка; бар — по
  `rune_recharge_s`, фаза такта из патчей тикера); протокол:
  `MagicConfig.rune_recharge_s` (фолбэк 30 с для старых серверов).
- **Инкрустация стоки** (как заточка): вставка в стак (qty>1) — в
  одну штуку: целевая отдельной строкой, стак −1, окно следует за
  новым uid; руны из стака расходовались по одной (проверено);
  логи открытия/закрытия окна инкрустации — для диагностики бага
  «окно закрывается сразу» (ждём воспроизведения в новой сборке).
- **Фикс stale-меню**: открытие любого окна чистит оба контекстных
  меню — окно подятия рисует общий `backpack_grid`, и меню рюкзака
  самооткрывалось при открытии лута (тест
  `opening_popup_clears_both_context_menus`).
